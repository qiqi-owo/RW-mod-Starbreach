本模组拥有多种阵营,相较于原版更高的经济收入
轻松快节奏,没有复杂的前置科技,无论PVP还是PVE都将给您带来愉悦的对局

1. 下载 `.rwmod` 文件
2. 放到铁锈战争 Mods 文件夹
3. 启动游戏，在 Mod 菜单中启用
